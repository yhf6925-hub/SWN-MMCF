## Minimum reporting checklist

- Record train/validation/test splits if any learned component is used.
- State whether OpenVINS online calibration options were enabled.
- Report camera and IMU rates, time-offset handling, and dropped-message policy.
- Publish every non-private parameter used for each reported table or figure.
- State the trajectory alignment and evaluation metrics used for ATE/RPE.
- Record whether failed initializations or runs were excluded, including the exclusion rule.
